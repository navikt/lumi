# Miljøer og lenker

## Dashboard

| Miljø | URL |
| :--- | :--- |
| Demo | https://lumi-dashboard-demo.ekstern.dev.nav.no |
| Dev | https://lumi-dashboard.ansatt.dev.nav.no |
| Prod | https://lumi-dashboard.ansatt.nav.no |

Demo-miljøet er åpent for alle og viser testdata. Det lagrer ingen endringer. Dev og prod krever Nav-innlogging, se [Tilgang](/dashboard/tilgang).

Dev og prod har hver sin Lumi API og database. Svar og surveydefinisjoner fra dev vises ikke i prod, og omvendt.
